# JS Practices

This project is a mini practice project designed to help improve JavaScript skills through various exercises and examples.

## Project Structure

```
js-practices
├── src
│   ├── index.js          # Main entry point for the application
│   ├── styles.css        # Styles for the application
│   └── utils
│       └── helpers.js    # Utility functions
├── tests
│   └── helpers.test.js    # Unit tests for utility functions
├── package.json          # npm configuration file
├── .gitignore            # Files and directories to ignore by Git
└── README.md             # Project documentation
```

## Setup Instructions

1. Clone the repository:
   ```
   git clone https://github.com/fahaman/JS-practices.git
   ```

2. Navigate to the project directory:
   ```
   cd JS-practices
   ```

3. Install the dependencies:
   ```
   npm install
   ```

## Usage

- To run the application, execute:
  ```
  npm start
  ```

- To run the tests, execute:
  ```
  npm test
  ```
